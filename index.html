Content Scheduler

本ツールは、画像コンテンツ（スライド形式の情報画像）を作成し、運営者自身のSNSアカウントへ 予約投稿するための個人用・非公開のコンテンツ管理ツールです。

What is this? (English)

This is a personal, self-hosted content scheduling tool operated by an individual. It generates image slides and schedules / publishes them to the operator's own social media accounts (including the operator's own Pinterest boards). It is not offered as a service to third parties, and it does not collect any data from other users.

主な機能 / Features

  • スライド画像（1080×1920）の自動生成 / Automated slide image generation
  • 運営者自身のSNSアカウントへの予約投稿 / Scheduled posting to the operator's own accounts
