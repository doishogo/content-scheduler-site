プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-06-05

1. 概要 / Overview

Content Scheduler（以下「本ツール」）は、運営者個人が自身のSNSアカウントへコンテンツを 予約投稿するために運用する、個人用・非公開のツールです。第三者にサービスとして提供する ものではありません。

Content Scheduler ("the Tool") is a personal, self-hosted application operated by an individual solely to schedule and publish content to the operator's own social media accounts. It is not provided as a service to any third party.

2. 収集する情報 / Information We Collect

本ツールは、運営者本人以外の利用者を持たないため、第三者の個人情報を一切収集しません。 連携先SNS（Pinterest 等）の API を通じて取得・保存する情報は、運営者自身のアカウントに関する 認証トークンおよび投稿管理に必要な情報（ボードID・投稿ステータス等）に限られます。

The Tool has no users other than the operator and does not collect any personal data from third parties. Data obtained via connected social media APIs (e.g., Pinterest) is limited to the operator's own authentication tokens and information necessary to manage the operator's own posts (board IDs, post status, etc.).

3. 情報の利用目的 / How We Use Information

取得した情報は、運営者自身のアカウントへの投稿作成・予約・公開、およびその状態確認のためにのみ 使用します。広告・分析・第三者提供の目的では使用しません。

Collected data is used only to create, schedule, publish, and monitor posts on the operator's own accounts. It is never used for advertising, analytics, or sharing with third parties.

4. 情報の保管 / Data Storage

認証トークン等の情報は、運営者が管理するサーバー内にのみ保存され、外部に送信されることは ありません（連携先SNSの公式APIとの通信を除く）。

Authentication tokens and related data are stored only on a server controlled by the operator and are never transmitted elsewhere, except for communication with the official APIs of the connected social networks.

5. 第三者への提供 / Data Sharing

個人情報を第三者に販売・共有・提供することはありません。

We do not sell, share, or disclose any personal data to third parties.

6. データの削除 / Data Deletion

連携の解除はいつでも可能であり、解除時に保存された認証トークンは無効化・削除されます。

Connections to social networks can be revoked at any time, upon which stored authentication tokens are invalidated and deleted.

7. お問い合わせ / Contact

本ポリシーに関するお問い合わせは、本サイトを公開している GitHub アカウント宛にご連絡ください。

For questions about this policy, please contact the GitHub account hosting this site.
